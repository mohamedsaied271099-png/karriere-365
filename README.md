# 🚚 Karriere 365: كورسات اللوجستيك وطريق الـ Ausbildung

أخو Deutsch 365. بينظم كورساتك ولينكاتها، ويذاكرك ساعة في اليوم من الصفر، ويراجعك، ويقترح كورسات تقوي السي في لـ Ausbildung لوجستيك في ألمانيا.

## التكلفة
كله ببلاش: من غير سيرفر، والـ AI شغال على اشتراكك في Claude / ChatGPT.

## أول مرة
1. ⚙️ الإعدادات ← انسخ التعليمات وحطها في Project اسمه "Karriere 365" في Claude.
2. 📚 كورساتي ← 🤖 رتبهم مع Claude ← الصق لينكاتك ← افتح في Claude ← الصق رده ← استورد.
3. 💡 المقترحات ← ضيف اللي يناسب مرحلتك.
4. كل يوم: 📅 النهارده.

## 💼 الوظايف
- 🤖 Claude (بالـ Web search) يدور على عروض Ausbildung في المواقع الرسمية وغير الرسمية ومواقع الشركات، وترجع العروض للتطبيق بمدى مناسبتها ليك.
- 🔎 لينكات بحث جاهزة لكل المواقع (Arbeitsagentur، IHK، ausbildung.de، Indeed، LinkedIn، ...).
- متابعة كل فرصة: جديدة ← هقدم ← قدمت ← مقابلة ← عرض، و Anschreiben مخصوص لكل شركة.

## 👤 بروفايلي
- استورد السي في القديم مع Claude، وارفع شهاداتك (بتتحفظ على جهازك بس).
- الـ Lebenslauf الألماني بيتبني لوحده، وكل إنجاز (كورس، شهادة، تقديم) بيطلّع نسخة جديدة منه. نزّله PDF أو خلّي Claude يحسّنه.

## نظام الأسبوع (ساعة في اليوم)
السبت–التلات: درس جديد · الأربع: تطبيق عملي · الخميس: مراجعة وامتحان · الجمعة: نص ساعة مصطلحات لوجستيك بالألماني (بتروح لبطاقات Deutsch 365 لو التطبيقين على نفس الموقع)

## الملفات
- `catalog.js`: الكورسات المقترحة، مراحل السنة، خطوات الـ Ausbildung، المهن
- `ai.js`: برومبتات الـ Agent (الترتيب، الشرح، الامتحان، المصطلحات، السي في، المقابلة)
- `app.js`: الواجهة والتقدم والمراجعة
- تقدمك محفوظ في المتصفح، فخد **نسخة احتياطية** كل أسبوع.
